
# Event Management System

An all-in-one platform for event organisers. Users can create events, manage registrations, and view attendance metrics.

## Features

- **Create Events**: Users can create new events by providing details like event name, date, and description.
- **Event Registration**: Users can register for events directly from the website.
- **View Events**: A list of all created events is available for users to browse.
- **Attendance Metrics**: Organisers can view real-time attendance metrics for their events.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js (or mention other backend technologies if used)
- **Database**: MongoDB (or mention other database if used)

## Installation

Follow these steps to get your local copy of the project up and running:

1. **Clone the repository** to your local machine:

   ```bash
   git clone https://github.com/your-username/event-management-system.git
   ```

2. **Navigate to the project folder**:

   ```bash
   cd event-management-system
   ```

3. **Open the `index.html` file** in your browser to run the application locally.

   Alternatively, you can use a local server like **Live Server** in Visual Studio Code or set up a server if you have a backend.

## Usage

Once the website is running, you can:

- **View a list of events** on the homepage.
- **Create new events** by navigating to the "Create Event" page.
- **Register for events** by going to the "Register" page.
- **View attendance metrics** for each event in real time (for organisers).
